# Google-Search-Homepage-Recreation-Assignment

## About the Project

This project is a recreation of the Google Search homepage, developed as part of my second-year ICT Application Development coursework at Berea College of Technology.

The purpose of this assignment was to demonstrate my understanding of front-end web development, including webpage layouts, element positioning, spacing, alignment, and styling. The project focuses on recreating the appearance of Google's search landing page using HTML and CSS.

## Technologies Used

- **HTML5:** Used to structure the webpage and its elements.
- **CSS3:** Used to style the webpage, including its layout, colours, spacing, and positioning.
- **Downloaded Images:** Used for the visual elements included in the recreation.

## Project Limitations

This project is a visual recreation of the Google Search landing page and is **not a fully functional search engine**. It focuses on the appearance and layout of the original homepage rather than Google's actual search functionality or backend systems.

Some elements may be displayed for visual purposes only and may not perform the same functions as they do on the original Google website.

## How to Run the Project

Follow these steps to view the recreated homepage on your computer:

1. **Download the project:** Download the repository from GitHub by clicking the green **Code** button and selecting **Download ZIP**.
2. **Extract the files:** If you downloaded a ZIP file, extract it to a folder on your computer.
3. **Keep the files together:** Make sure the HTML file, CSS file, and downloaded images remain in their original folders and locations so that the webpage can load them correctly.
4. **Open the homepage:** Locate the file named `index.html` and double-click it to open the webpage in your default browser.
5. **View the project:** The recreated Google Search homepage should now appear in your browser.

**Note:** You do not need to install any additional software or set up a server to view this project, provided the files and their paths are correct.
